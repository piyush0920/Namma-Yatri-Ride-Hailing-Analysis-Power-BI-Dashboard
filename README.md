# Namma-Yatri-Ride-Hailing-Analysis-Power-BI-Dashboard
End-to-end data visualization project on the Namma Yatri dataset — covers data modelling (star schema, role-playing dimensions), EDA across 37 Bengaluru zones, DAX measures for cancellation/completion rates, and strategic recommendations. Built as part of the Advanced Data Visualisation module at IIIT Bangalore.
